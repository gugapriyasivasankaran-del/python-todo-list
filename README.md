# python-todo-list 

A simple command-line to-do list built with Python. Tasks are saved to a JSON file, so they stay after you close the program.

## Features
- Add, view, complete, and delete tasks
- Saves tasks automatically to `tasks.json`
- Handles invalid input without crashing

## How to run
1. Install Python 3
2. Download `todo.py`
3. Run: `python todo.py`

## What I learned
- Reading and writing JSON files
- Using functions to organize code
- Handling errors with try/except
